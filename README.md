# Claude Puzzles

Logic puzzles solved and turned into animated explainer videos, plus one designed puzzle game. Each video folder holds the puzzle image, the finished video, the solver used to find and check the solve path, and the source that renders the video. Ninefold holds the playable page, its walkthrough, the design and verification tools and the game's source.

| Folder | Puzzle | Video |
|---|---|---|
| [01-full-rank-index-zipper](01-full-rank-index-zipper/) | 9×9 Latin square with Full Rank clues, index lines and zipper lines | *Every Clue Is an Address* (17:06) |
| [02-cipher-loop](02-cipher-loop/) | 12×12 loop puzzle with group sums and a letter cipher | *Cipher Loop* (13:09) |
| [03-ninefold](03-ninefold/) | A sudoku that grows over five acts, from a 4×4 to fog of war, invented terrain rules and line panels on a 3D island | Playable page + walkthrough PDF |

The videos are stored with Git LFS. Run `git lfs pull` after cloning to download them.
